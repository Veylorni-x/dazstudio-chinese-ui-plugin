# 本机版本与官方接口核对

核对目标：Daz Studio 6.26.2026.30901，General Release，Windows x64；本机启动记录报告 Qt 6.10.3。

## Daz 官方资料

- Daz 6 更新记录：`https://docs.daz3d.com/public/software/dazstudio/6/change_log`
  - 6.25.2025.30214 增加 `DzApp.getUiLanguage()`、`setUiLanguage()` 和脚本属性 `uiLanguage`。
  - 记录了多个语言文件共存和 `-language` 命令行选项。
  - 6.26 对原生 SDK 插件增加 SDK 版本检查，旧版插件需要使用匹配 SDK 重新编译。
- Daz Studio 6 SDK 产品资料：`https://www.daz3d.com/daz-studio-6-sdk`
  - 使用 C++ 与 Qt，需要另行取得 Qt 6.10 开发环境。
- Daz 命令行与独立实例：`https://docs.daz3d.com/public/software/dazstudio/4/referenceguide/tech_articles/command_line_options/start`

本机同时检查了 DzCore 导出的实际接口名称以及安装文件。语言扩展使用 Qt 接口，未以猜测的旧版 Daz SDK 结构调用程序内部对象。

## 显示层策略

- 标准对话框采用 Qt 官方中文语言文件。
- Daz 界面文字在到达菜单、按钮、标签、工具提示和只读帮助后翻译。
- 列表绘制时使用中文显示副本，保留原模型、原委托、数值编辑和选择操作。
- Daz 对象构造、参数标签构造和枚举数据不经过全局词典翻译。
- 不替换 Daz DLL，不修改导出器和原素材。
