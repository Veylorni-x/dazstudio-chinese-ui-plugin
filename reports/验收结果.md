# Daz Studio 简体中文汉化验收

目标版本：Daz Studio 6.26.2026.30901，Windows x64，Qt 6.10.3。验收使用本机程序、隔离的 Daz 测试实例、DAZ Script 接口和原始素材。最后一轮完整工作流正常退出，Windows 进程退出码为 `0`。

**已实测**

- 简体中文主词库 30,271 条（已清洗 1,580+ 条二进制/JS/着色器代码碎片与机器翻译幻觉词条，补充校正 1,430+ 条核心界面与术语词条），来源包括程序和内置插件文字、本地帮助与操作提示、着色器说明，以及默认素材、Genesis 9 和 dForce 入门素材的名称、分类、参数与元数据。
- 原生 Daz Studio 6.26 SDK 插件架构（`DzPlugin` ABI，`SDK 6.26.2026.30200` + Qt `QGenericPlugin` 双模兼容）：`App.getPluginMgr().findPlugin("Daz Studio 简体中文 (Simplified Chinese)")` 实测返回 `found: true`、状态 `Loaded (0)`、版本 `1.0.0.0`，可在“帮助 → 关于已安装插件”中查看，同时支持管理员安装至 `plugins/` 目录或普通用户免管理员权限运行。
- 3D 视口右上角 HUD 视图选择器（`Perspective View` → `透视视图`）及相机方位方块六个面（`Front / Back / Top / Bottom / Left / Right` → `正面 / 背面 / 顶面 / 底面 / 左侧 / 右侧`）均已通过 `DzCameraCubeCombinedTexture::paint` 与 `DzStyle::drawPrimitive` 离屏贴图绘制挂钩完成汉化，实测截图见 `reports/screenshots/03-viewport-character-zh.png`。
- 实测菜单、素材库、参数、Surfaces、Shaping、Posing、Render Settings 和 Simulation Settings。错误对话框显示“无法打开文件”。
- Parameters、Render Settings 菜单项通过 Daz 的 `DzActionMenu` 接口读取，并用 Daz 同一 Qt 绘制风格显示中文预览。截图在 `reports/screenshots/04-parameters-options-zh.png` 和 `reports/screenshots/06-render-options-zh.png`。
- 加载 Genesis 9 后共有 316 个场景节点。`XTranslate` 改为 3.25，保存 DUF 并重新打开后仍为 3.25；OBJ 导出成功，包含 142,850 个顶点。
- 英文与中文切换后角色、节点名称、属性内部标识、搜索素材路径和导出均正常。
- `dForce` 保留为 Daz 的官方产品术语，不会被当作“部队”翻译。
- 本地简体中文说明和两篇随程序安装的本地帮助随包保存；词库可以独立编辑和重新加载。
- 修复了初版插件退出时对象被重复释放的问题。原版 Daz 和修复版均完成保存导出对照；最终完整工作流正常退出。原程序及原来的用户配置文件均通过哈希核对。

内置操作提示在本轮加入了本地文本资源，并对 Surfaces 操作说明进行了人工修订。在线帮助链接随断网状态保持可打开目标站点的原始链接，本地离线说明见 `help/index.html`。

菜单截图使用 Daz 返回的真实选项条目生成非模态预览，验证这些项目在 Qt 绘制路径上的译文。测试没有模拟鼠标去实际触发某个属性的右键菜单。

**崩溃与布局修复总结**

1. **退出崩溃修复**：初版为同一个通用语言插件对象设置了 `QObject` 应用父对象，而 Qt 也把该对象加入自身的通用插件清理列表，导致退出时重复释放。修复后移除重复父所有权，并在双模加载下确保 `Controller` 单例唯一，连续完整工作流退出码均为 `0`。证据和版本记录见 `reports/crash-analysis.json`。
2. **工具栏拆分与布局污染修复**：将窗口标题挂钩严格限制在 `QDialog` 派生对话框，并在主窗口关闭保存 `layout.dsx` 前自动移除临时语言工具栏、还原菜单栏动作英文原文，确保 `layout.dsx`、`toolbars.dsx`、`actions.dsx` 零污染。
