Daz Studio 离线中文帮助

适用：Daz Studio 6.26.2026.30901，Windows 64 位。本页随汉化包保存在电脑上，断网也能打开。

切换语言 · 加载角色 · 参数与姿势 · 材质 · 相机与灯光 · 渲染 · 动画与模拟 · 保存与导出 · 补充翻译

切换中文和英文

通过“启动中文版”进入软件。窗口工具栏上的“语言 / Language”提供“简体中文”和“English”两个选项，切换后继续使用当前场景。关闭软件后，也可以用“启动英文版”进入原来的英文界面。

汉化词库保存在安装文件夹的 dictionary 内。语言选择保存在汉化自己的设置文件中。场景、素材、参数的原始标识和素材目录仍使用原来的数据。

加载角色和素材

  1. 打开“窗口 → 面板（选项卡）→ 素材库”或“智能素材”。
  2. 在素材库中展开 Daz Studio 格式下的素材目录，再进入人物、服装、毛发等分类。
  3. 双击素材缩略图加载。加载服装、毛发之前，先在场景面板选中对应角色。
  4. 如果出现角色附加组件选择窗口，按需要选择形变等附加内容，再确认加载。

素材显示名称可以是中文，磁盘文件名与搜索数据仍是原来的英文。原来的英文关键词、文件路径和脚本引用可以继续使用。素材未出现在库里时，先检查“首选项 → 素材目录管理器”中的目录配置。

选择、参数、塑形和姿势

“场景”面板列出角色、骨骼、灯光、相机和道具。先选中对象，再使用“参数”“塑形”或“姿势”面板。

  • 平移决定位置，旋转决定朝向，缩放决定大小。三个轴的原始字母标识继续保留。
  • 塑形改变体形与外观；姿势控制改变身体动作和表情。
  • 拖动滑块调整数值，也可以在数值处输入。需要恢复时使用参数菜单的重置功能。
  • 参数菜单中可以查看设置、限制、隐藏属性和收藏项。
  • 通用工具结合移动、旋转和缩放。需要精确操作时，可分别使用平移、旋转或缩放工具。

关节和形变参数有各自的范围。先保存场景，再进行大幅度调整，便于回到之前的状态。

表面、材质和贴图

  1. 选中对象，打开“表面材质”面板。
  2. 选择需要修改的表面区域。
  3. 在编辑器中调整基础颜色、粗糙度、金属度、透明度等参数；或者切换到预设页应用材质。

基础颜色控制物体的主要颜色；粗糙度影响反射的模糊程度；金属度控制金属表现；法线贴图与凹凸贴图表现表面细节；置换会影响表面形状；自发光使材质产生发光效果。

材质参数随着色器而变化。Iray、Filament 和其他渲染器有各自的参数。UV 是贴图在模型上的坐标，汉化保留这些技术标识。

相机、视图和灯光

透视视图适合摆放场景。需要固定构图时，使用“创建 → 新建相机”，再从视口的视图列表切换到该相机。

  • 焦距影响视角，景深控制清晰范围。
  • 点光源向四周照明，聚光灯朝指定方向照明，平行光适合模拟远处光源。
  • 灯光的强度、光通量、颜色和色温共同影响照明。
  • 环境贴图和穹顶提供环境照明；需要时可显示穹顶和地面。

先用简单光照确认角色和构图，再逐步调整材质和渲染质量，便于判断每项修改的效果。

渲染与输出

  1. 打开“渲染设置”，选择要使用的渲染引擎。
  2. 检查输出尺寸、宽高比、当前相机和保存位置。
  3. 先用较小尺寸查看构图、灯光和材质，再设置正式输出尺寸。
  4. 渲染结束后保存图像。

采样数和最长时间影响渲染过程。色调映射中的曝光、白点、对比度等影响图像表现。使用显卡渲染时，模型和贴图所占用的显存会影响能否使用该设备。

动画和模拟

打开时间轴，设置帧率和播放范围。在不同帧调整对象参数并建立关键帧，即可形成动画。检查关键帧的插值方式，可以调整动作变化的节奏。

dForce 模拟用于支持该功能的服装、毛发等素材。确认碰撞关系、起始姿势和模拟范围后，在“模拟设置”中运行模拟。需要重新计算时，先清除对应模拟结果，再调整设置。

场景中的素材是否支持模拟，由素材本身决定。汉化显示不会给普通素材额外添加模拟功能。

保存、重新打开和导出

  1. 使用“文件 → 另存为 → 场景”保存完整场景。
  2. 需要继续工作时，从“文件 → 打开”重新打开场景。
  3. 只保存某些对象时，使用相应的场景子集或预设保存功能。
  4. 给其他软件使用时，选择“文件 → 导出”，再选择 OBJ、FBX 等格式和合适的选项。

场景文件保存了对象与素材的引用，通常仍需要原来的素材库。导出前检查单位、坐标轴、可见对象、材质和动画范围。目标软件支持的内容各有不同，按对应导出窗口的选项设置。

自己补充和修改翻译

优先编辑 dictionary/overrides.json。在 strings 中填写“英文原文”： “中文译文”，保存为 UTF-8，再从语言按钮选择“重新加载词库”。补充普通文字时不需要重新编译插件。

原文中的 %1、%2、%n 等是软件填入数值或名称的位置，修改译文时保留它们。带有尖括号的帮助文字可能包含排版和链接，也应保留这些标签。

“导出漏翻清单”会把遇到的文字记录到汉化安装目录的 reports/coverage-runtime.json。记录保存在本机，便于后续补充。

卸载与升级

关闭 Daz 后运行“卸载汉化”。已安装副本的自定义词库会先备份到“文档”中的词库备份文件夹。Daz 主程序和素材保留。

Daz 升级后，先运行“检查兼容性”。主程序或 Qt 版本变化时，按随包说明重新核对和编译。这里的 Qt 指 Daz 用来绘制窗口的界面组件。
